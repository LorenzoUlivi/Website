# Lorenzo Ulivi — academic website

React, TypeScript, Vite and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

Build with `npm run build`. Update the `papers` array in `src/main.tsx` to edit featured publications.

## Add the supplied assets

Place the hero image at `public/images/arp220-mrk231-outflows.png` and the PDF at `public/documents/Lorenzo_Ulivi_CV.pdf`. Until then, the site uses an abstract CSS astronomical background and offers a contact link for requesting the CV. Once the PDF is present, download and open controls appear automatically.
